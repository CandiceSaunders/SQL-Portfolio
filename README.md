# SQL Data Analysis Projects

This repository contains a collection of SQL-based data analysis and operational reporting projects focused on Agile delivery, business operations, KPI reporting, and process analysis. These projects were created to strengthen SQL querying, data validation, transformation, and reporting skills while working through realistic business and operational reporting scenarios.

The portfolio demonstrates experience with data ingestion workflows, staging tables, SQL views, aggregations, KPI analysis, and operational reporting using SQL Server. Many of the projects are also designed to support reporting and dashboard development in tools such as Power BI, Tableau, and Microsoft Excel.
